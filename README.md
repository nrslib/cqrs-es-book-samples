# CQRS+ES実践ガイド サンプルコード

書籍『CQRS+ES実践ガイド イベント駆動型モデリング／システム構築手法』のサンプルコードです。

## 必要な環境

- Java 25
- Bash、curl、jq
- Docker（一部の統合テストで使用）

Dockerが使えない環境では、Dockerを必要とするテストはスキップされます。

## ビルドとテスト

リポジトリ直下で実行します。

```bash
./gradlew build
```

[mise](https://mise.jdx.dev/)を利用する場合は次のコマンドで実行できます。

```bash
mise exec -- ./gradlew build
```

## アプリケーションの起動

リポジトリ直下で、起動するアプリケーションのコマンドを実行します。

| アプリケーション | コマンド |
|---|---|
| ユーザCRUD | `./gradlew :02:bootRun` |
| 予約システム | `./gradlew :reservation:bootRun` |

どちらもインメモリのH2データベースを使うため、データベースの事前準備は不要です。HTTP APIは`http://localhost:8080`で待ち受けます。同じポートを使うため、1つずつ起動してください。

停止するときは`Ctrl+C`を押します。停止するとデータは消えます。
